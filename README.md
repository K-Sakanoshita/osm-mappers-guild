# OSM Mappers Guild（OSMマッパーズギルド）

「この地域をマッピングしてほしい」という依頼者と、OpenStreetMap（OSM）を編集するマッパーをつなぐWebサービスです。

依頼者が対象地域・内容を投稿し、マッパーが自由に参加して OSM で作業します。Changeset で成果を報告し、依頼者が確認・承認することで活動実績を蓄積します。原則無償のプラットフォームで、依頼には任意の「報酬・謝礼」自由記述欄を設けられますが、ギルドは決済・支払い保証・仲介を行いません（当事者間の扱いです）。

全体構想とロードマップは Issue #1 を参照してください。本リポジトリには Phase 1（MVP: 投稿 → 参加 → OSM編集 → 報告 → 確認 の最小ループ）の実装が含まれます。

## 構成

| パス | 内容 |
|---|---|
| `frontend/` | 静的フロントエンド（ビルド不要、MapLibre GL JS + OSM実データ）。GitHub Pages で公開 |
| `api/` | PHP API（OSM OAuth 2.0 ログイン、依頼・参加・報告・承認） |
| `db/` | DBスキーマ（本番 MySQL / 開発用 SQLite） |
| `docs/` | 開発・配置手順 |
| `.github/workflows/pages.yml` | フロントエンドの GitHub Pages デプロイ |

## 主な機能（Phase 1 MVP）

- OSM OAuth 2.0 ログイン（ユーザーは表示名ではなく OSM ユーザーIDで識別）
- 地図（OSM実データ）上で矩形の対象エリアを指定して依頼を作成・編集・取り下げ
- 依頼の一覧・詳細、状態（募集中・作業中・確認待ち・修正依頼・完了・取り下げ）とカテゴリでの絞り込み
- マッパーの参加表明・参加解除（依頼者自身も参加可能、一人が複数依頼へ同時参加可）
- 作業報告（コメント＋複数の Changeset ID、サーバー側で編集者・bbox・変更件数を確認）。編集不要の現地確認報告にも対応
- 依頼者による確認・承認・修正依頼、履歴表示。複数人参加時は全員が承認されるまで「完了」にしない
- 認可処理（他人の依頼の改変防止）、入力検証、CSRF・CORS 対策
- 依頼の通報・管理者の非表示/復元、管理者操作履歴

## クロスドメイン認証の注意

GitHub PagesとさくらAPIを別サイトで直接接続すると、Cookie制限によりOSMログイン後も未ログインになる場合があります。
**[Cloudflare Workerによる同一サイトAPI化](docs/SAME_SITE_AUTH.md)** に移行する場合は、WorkerとOAuth Redirect URI・PHP設定を先に整えてからフロントエンドを公開してください。

## Phase 2（今回の追加機能）

- 依頼ごとの「いいね」（ログインユーザーにつき1回、解除可能）
- 依頼者が承認したマッパーの成果ごとの「いいね」（ログインユーザーにつき1回、解除可能）
- デイリークエストは今後の開発段階。今回の変更には含めない

既存の Phase 2 DB は `db/migrations/003_unify_likes.mysql.sql` で依頼と成果のいいねを統合します。移行時はいいね操作を停止し、[配置手順](docs/DEPLOY.md)に従ってください。

最新のDB変更手順（マイグレーション004）と管理者設定は [本番配置手順](docs/DEPLOY.md) を参照してください。
